# Technical Requirements Document (TRD)
## AI-Based Crop Recommendation for Farmers
**Smart India Hackathon 2025 | Problem Statement ID: 25030**

---

### 1. Document Overview

**Purpose:** This Technical Requirements Document (TRD) details the system architecture, technology stack, data models, API specifications, performance benchmarks, and deployment strategy for the "AgriMitra" AI-Based Crop Recommendation platform. It serves as the blueprint for development during the Smart India Hackathon.

**Scope:** Covers the entire system, including the mobile/web frontend, AI/ML backend, data acquisition pipelines, and infrastructure requirements.

**Target Deployment:** Minimum Viable Product (MVP) with scalability to support pan-India rollout.

---

#### 2.2 Architecture Components

|-----------|------------|----------------|
| **Frontend** | Flutter / React Native (Mobile)<br/>React + TypeScript + Tailwind CSS (Web) | User interface, multilingual support, voice input/output, offline caching |

### 4. Data Specifications

#### 4.1 Input Feature Schema

Model input features, ranges, and units based on the standard Crop Recommendation Dataset:

| Feature | Symbol | Range | Unit | Description |
|---------|--------|-------|------|-------------|
| Nitrogen | N | 0 - 100 | kg/ha | Soil nitrogen content |
| Phosphorus | P | 0 - 100 | kg/ha | Soil phosphorus content |
| Potassium | K | 0 - 100 | kg/ha | Soil potassium content |
| Temperature | Temp | -10 - 50 | °C | Ambient temperature |
| Humidity | Hum | 0 - 100 | % | Relative humidity |
| pH | pH | 0 - 14 | - | Soil pH level |
| Rainfall | Rain | 0 - 500 | mm | Annual/Seasonal rainfall |

#### 4.2 Output Schema

| Field | Type | Description |
|-------|------|-------------|
| `recommended_crop` | string | Primary crop recommendation |
| `crop_id` | integer (1-22) | Numeric identifier for crop |
| `confidence` | float (0-1) | Model confidence score |
| `top_alternatives` | array | Top 2-3 alternative crops with scores |
| `reasoning` | string | Human-readable explanation |
| `timestamp` | datetime | Recommendation generation time |

#### 4.3 Supported Crops (22 Types)

Rice, Maize, Jute, Cotton, Coconut, Papaya, Orange, Apple, Muskmelon, Watermelon, Grapes, Mango, Banana, Pomegranate, Lentil, Blackgram, Mungbean, Mothbeans, Pigeonpeas, Kidneybeans, Chickpea, Coffee

#### 4.4 Database Schema (Core Tables)

**Users Table:**
```sql
CREATE TABLE users (
    id UUID PRIMARY KEY,
    phone VARCHAR(15) UNIQUE,
    name VARCHAR(100),
    preferred_language VARCHAR(10),
    location_lat DECIMAL(10,6),
    location_lng DECIMAL(10,6),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Query History Table:**
```sql
CREATE TABLE queries (
    id UUID PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    input_features JSONB, -- {N, P, K, temp, humidity, pH, rainfall}
    recommended_crop VARCHAR(50),
    confidence FLOAT,
    response_time_ms INTEGER,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Weather Cache Table:**
```sql
CREATE TABLE weather_cache (
    location_key VARCHAR(100) PRIMARY KEY,
    temperature FLOAT,
    humidity FLOAT,
    rainfall FLOAT,
    forecast_data JSONB,
    cached_at TIMESTAMP,
    expires_at TIMESTAMP
);
```

### 5. API Specifications

#### 5.1 Core Endpoints

| Method | Endpoint | Description | Request Body | Response |
|--------|----------|-------------|--------------|----------|
| POST | `/api/v1/recommend` | Get crop recommendation | `{N, P, K, temp, humidity, pH, rainfall, location?}` | `{crop, confidence, alternatives, reasoning}` |
| GET | `/api/v1/weather` | Get weather data | Query: `{lat, lng, state, district}` | `{current, forecast, irrigation_advice}` |
| GET | `/api/v1/market` | Get commodity prices | Query: `{commodity, mandi}` | `{price, demand_score, trend}` |
| GET | `/api/v1/health` | System health check | - | `{status, model_loaded, cache_hit}` |

#### 5.2 POST /api/v1/recommend - Request/Response Example

**Request:**
```json
{
    "N": 50,
    "P": 30,
    "K": 40,
    "temperature": 28.5,
    "humidity": 65,
    "pH": 6.5,
    "rainfall": 200,
    "location": {
        "lat": 22.5726,
        "lng": 88.3639
    }
}
```

**Response:**
```json
{
    "recommended_crop": "Rice",
    "crop_id": 1,
    "confidence": 0.94,
    "top_alternatives": [
        {"crop": "Maize", "crop_id": 2, "confidence": 0.82},
        {"crop": "Jute", "crop_id": 3, "confidence": 0.71}
    ],
    "reasoning": "High rainfall (200mm) and moderate temperature (28.5°C) are ideal for rice cultivation. Soil pH 6.5 is within optimal range for rice (5.5-7.0).",
    "timestamp": "2026-07-28T10:30:00Z",
    "response_time_ms": 145
}
```

### 6. ML Model Specifications

#### 6.1 Model Selection

| Model | Accuracy | Rationale |
|-------|----------|-----------|
| **Random Forest Classifier** | ~95%+ | Robust to non-linear relationships, handles categorical features well |
| **XGBoost** | ~95%+ | Higher performance, handles missing data |
| **K-Nearest Neighbors** | 91.3% | Simpler, good baseline, interpretable |

**Primary Choice:** Random Forest Classifier - optimal balance of accuracy, training speed, and interpretability.

#### 6.2 Training Specifications

| Parameter | Value |
|-----------|-------|
| Dataset Size | ~2,200 records, 22 crops |
| Training/Test Split | 80/20 stratified |
| Cross-validation | 5-fold |
| Feature Scaling | StandardScaler + MinMaxScaler |
| Primary Metric | Accuracy, F1-Score |

#### 6.3 Model File Specifications

| Format | File Extension | Size (Est.) |
|--------|----------------|-------------|
| Pickle (Scikit-learn) | `.pkl` | ~5-10 MB |
| Joblib | `.joblib` | ~5-10 MB |

#### 6.4 Scaler Dependencies

```
# Required scalers for input preprocessing
crop_predict_standscaler.pkl  # StandardScaler
crop_predict_minmaxscaler.pkl # MinMaxScaler
crop_predict_model.pkl        # Trained classifier
```

#### 6.5 Sample Inference Code

```python
from huggingface_hub import hf_hub_download
import joblib
import numpy as np

# Load model and scalers
repo = "Arko007/agromind-crop-recommendation"
model = joblib.load(hf_hub_download(repo, "crop_predict_model.pkl"))
sc = joblib.load(hf_hub_download(repo, "crop_predict_standscaler.pkl"))
ms = joblib.load(hf_hub_download(repo, "crop_predict_minmaxscaler.pkl"))

# Input features
features = np.array([[50, 30, 40, 28, 65, 6.5, 200]])

# Preprocess and predict
features_scaled = sc.transform(ms.transform(features))
prediction = model.predict(features_scaled)
# Output: crop_id (1-22)
```

### 8. Offline-First Design

#### 8.1 Offline Capability Requirements

| Feature | Implementation | Storage |
|---------|----------------|---------|
| Weather Data | Cache last 7-day forecast | SQLite |
| Model Inference | Pre-loaded model on device | Local .pkl file |
| User Queries | Queue for sync when online | SQLite |
| Language Models | Pre-downloaded TTS models | Local storage |

#### 8.2 Sync Strategy

- **Immediate:** Queries stored locally, synced on reconnection
- **TTL-based:** Weather cache expires after 1 hour
- **Conflict Resolution:** Timestamp-based (latest wins)
