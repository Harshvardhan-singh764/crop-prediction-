**Smart India Hackathon 2025 | Problem Statement ID: 25030**

### 1. Complete User Journey Flowchart

This flowchart maps the entire user journey from app launch to receiving recommendations and utilizing post-recommendation features.

```mermaid
graph TD
    A[App Launch] --> B{First Time User?}
    B -->|Yes| C[Welcome/Language Selection Screen]
    B -->|No| D[Splash Screen → Home Dashboard]
    
    C --> E[Phone Number Registration]
    E --> F[OTP Verification]
    F --> G{Authentication Success?}
    G -->|No| E
    G -->|Yes| D
    
    D --> H{User Action}
    
    %% Core Recommendation Flow
    H -->|Tap 'Get Recommendation'| I[Input Method Selection]
    I --> J{Voice Input Available?}
    J -->|Yes| K[Voice Input Screen<br/>'Speak Now' with Mic]
    J -->|No| L[Manual Input Form<br/>Soil/Weather/Location]
    
    K --> M[Speech-to-Text Processing]
    M --> N[AI Extracts Parameters<br/>N,P,K,temp,humidity,pH,rainfall]
    N --> O{Parameters Complete?}
    O -->|No| P[AI Asks Clarifying Questions<br/>Voice/Text]
    P --> K
    
    L --> Q[User Fills Form Fields]
    Q --> O

    AK -->|Yes| AH

    H -->|Tap 'Learn'| AT[Learning Center]
```

### 2. Detailed Screen-by-Screen Flow

#### 2.1 Onboarding & Authentication Flow

```mermaid
sequenceDiagram
    participant User
    participant App
    participant Backend
    participant SMSGateway
    
    User->>App: Opens App
    App->>User: Show Splash Screen (2s)
    App->>User: Language Selection Prompt
    
    User->>App: Selects Language (Hindi/Marathi/etc.)
    App->>User: Voice Welcome + Registration Screen
    
    User->>App: Enters Phone Number
    User->>App: Taps 'Get OTP'
    App->>Backend: POST /api/v1/auth/send-otp
    Backend->>SMSGateway: Send OTP SMS
    SMSGateway-->>User: OTP Received
    
    User->>App: Enters OTP
    App->>Backend: POST /api/v1/auth/verify-otp
    Backend-->>App: Auth Token + User Profile
    App->>User: Navigate to Home Dashboard
```

#### 2.2 Core Recommendation Flow (Detailed)

```mermaid
flowchart TD
    subgraph Input["Input Phase"]
        A[Dashboard<br/>Tap 'Get Recommendation'] --> B[Voice/Manual Input Screen]
        B --> C{Voice Input?}
        C -->|Yes| D[🎙️ Mic Active<br/>User Speaks]
        D --> E[STT Processing<br/>Converts to Text]
        E --> F[AI Extracts:<br/>- Soil Type/Color<br/>- Weather Conditions<br/>- Location<br/>- Water Source]
        F --> G{All params<br/>extracted?}
        G -->|No| H[AI Asks:<br/>'What is your soil pH?']
        H --> D
        G -->|Yes| I[Proceed to Processing]
        C -->|No| J[Manual Form]
        J --> K[Sliders/Dropdowns for:<br/>N, P, K, pH, Temp, Humidity, Rainfall]
        K --> I
    end
    
    subgraph Processing["Processing Phase"]
        I --> L[Show Loading Spinner<br/>'Analyzing Field Data...']
        L --> M[Backend API Call<br/>POST /api/v1/recommend]
        M --> N[ML Model Inference<br/>Random Forest/XGBoost]
        N --> O[Response Ready]
    end
    
    subgraph Output["Output Phase"]
        O --> P[Show Results Screen]
        P --> Q[🎵 TTS Announcement<br/>'Based on your field,<br/>Rice is recommended']
        P --> R[Primary Recommendation<br/>Crop Name + Confidence %]
        P --> S[Top Alternatives<br/>2-3 with scores]
        P --> T[Reasoning Section<br/>'Why this crop?']
        T --> U[Bullet Points:<br/>• Fits your soil pH<br/>• Ideal for current weather<br/>• High market demand]
    end
```

### 3. State Management & Transitions

| Screen | Entry Point | Exit Point(s) | Key UI Elements |
|--------|-------------|---------------|-----------------|
| **Splash Screen** | App Launch | Auto-transition after 2s | Logo, App Name |
| **Language Selection** | After Splash | Tap Language → Registration | Language cards (flags/text), "Continue" button |
| **Registration** | Language Selection | Submit → OTP Screen | Phone input field, "Get OTP" button |
| **OTP Verification** | Registration | Verify → Home | 6-digit OTP input, "Verify" button, Resend OTP |
| **Home Dashboard** | OTP Verification OR App Launch (returning) | Navigation to sub-screens | Recommendation CTA, Weather Widget, Quick Links |
| **Input Screen** | Home → "Get Recommendation" | Submit → Processing | Mic button, Form fields, "Get Suggestion" button |
| **Processing** | Input Submit | Auto → Results | Loading spinner, progress text (with audio) |
| **Results** | Processing Complete | Various (Market/Details/Chat/Back) | Crop card, Confidence, Alternatives, Action buttons |
| **Crop Details** | Results → "Learn More" | Back → Results | Sowing/ Harvesting/ Pest information with images |
| **Market Prices** | Results → "Check Prices" | Back → Results | Mandi list, Price trends, Alert button |
| **AI Chat** | Results → "Ask More" | Back → Results | Chat bubble interface, Voice input |
| **Learning Center** | Home → "Learn" | Back → Home | Topic cards, Progress bars |
| **Notifications** | Home → Notification Bell | Back → Home | Alert list with categories |
| **Soil Health** | Home → "Soil Health" | Back → Home | Input form, Analysis results |

### 4. Voice Interaction Flow (Multimodal)

The voice interface is a critical differentiator for low-literacy users. The voice flow is designed to be conversational and natural.

```mermaid
graph LR
    subgraph VoiceInput["Voice Input Flow"]
        V1[User: "Hello AgriMitra"] --> V2[App: "Hello! How can I help you today?"]
        V2 --> V3[User: "Recommend a crop for my field"]
        V3 --> V4[App: "Sure! Tell me about your soil and weather"]
        V4 --> V5[User: "I have black soil, it has rained 200mm this month, and I'm in Satara"]
        V5 --> V6[App: "Got it! What is your soil pH?"]
        V6 --> V7[User: "It's around 6.5"]
        V7 --> V8[App: "Analyzing... Based on this, Rice is the best crop for you"]
    end
    
    subgraph VoiceOutput["Voice Output Flow"]
        V8 --> O1[App: "🎵 Rice is the best crop for you this season"]
        O1 --> O2[App: "It has a confidence score of 94%"]
        O2 --> O3[App: "Would you like to know more about growing Rice?"]
        O3 --> O4{User Response}
        O4 -->|Yes| O5[App: "Provides detailed info via voice"]
        O4 -->|No| O6[App: "Returning to Home. Let me know if you need help!"]
    end
```

#### Voice Input Extraction Rules

| Extracted Parameter | Example User Phrase | Extraction Method |
|---------------------|---------------------|-------------------|
| **Location** | "I am in Satara" | Named Entity Recognition |
| **Soil Type** | "Black soil" / "Sandy soil" | Keyword matching + fuzzy search |
| **Rainfall** | "200mm rain this month" | Regex + numerical extraction |
| **Temperature** | "It's quite hot, about 30 degrees" | Keyword + numerical extraction |
| **pH** | "pH is around 6.5" | Keyword + numerical extraction |
| **Water Source** | "I have a borewell" / "Rainfed" | Keyword matching |

### 5. Error & Exception Handling Flow

```mermaid
graph TD
    A[User Action] --> B{Action Successful?}
    B -->|Yes| C[Continue Normal Flow]
    B -->|No| D[Error State]
    
    D --> E{Error Type}
    
    E -->|Network Error| F[Show: 'No Internet Connection']
    F --> G[Retry Button]
    G --> H{Retry}
    H -->|Success| C
    H -->|Fail| F
    
    E -->|Voice Recognition Error| I[Show: 'I didn't catch that']
    I --> J[Retry Voice Input]
    I --> K[Fallback to Manual Input]
    
    E -->|API Timeout| L[Show: 'Taking longer than expected']
    L --> M[Retry]
    L --> N[Use Cached Recommendation]
    
    E -->|Invalid Input| O[Show: 'Please enter valid value']
    O --> P[Highlight Field with Error]
    P --> Q[User Corrects Input]
    Q --> C
    
    E -->|Model Confidence Low| R[Show: 'The data is uncertain']
    R --> S[Display Alternative Options]
    S --> T[Suggest Soil Testing]
```

### 7. User State Persistence

```mermaid
stateDiagram-v2
    [*] --> NewUser: App Launch
    
    state NewUser {
        [*] --> LanguageSelection
        LanguageSelection --> Registration
        Registration --> OTPVerification
        OTPVerification --> Home: Success
    }
    
    state ReturningUser {
        [*] --> Splash
        Splash --> Home: Auto-login
    }
    
    state LoggedIn {
        Home --> Input
        Home --> Weather
        Home --> Learning
        Home --> SoilHealth
        Input --> Processing
        Processing --> Results
        Results --> Market
        Results --> Chat
        Results --> Details
    }
    
    NewUser --> ReturningUser: After Registration
    ReturningUser --> LoggedIn: Session Active
    LoggedIn --> ReturningUser: App Minimized
    ReturningUser --> [*]: Logout
```

### 8. Offline Mode State Flow

```mermaid
graph TD
    A[App Online] --> B[Network Check]
    B --> C{Internet Available?}
    C -->|Yes| D[Sync Data with Cloud]
    C -->|No| E[Switch to Offline Mode]
    
    D --> F[Update Local Cache]
    F --> G[Clear Pending Sync Queue]
    
    E --> H[Show Offline Banner]
    H --> I[Load Cached Weather]
    H --> J[Load Cached Recommendations]
    H --> K[Queue New Queries Locally]
    
    I --> L[User Interacts Offline]
    J --> L
    K --> L
    
    L --> M[Store Actions in SQLite]
    M --> N[Network Check Every 60s]
    N --> O{Reconnected?}
    O -->|Yes| P[Sync Queued Queries]
    O -->|No| H
    
    P --> Q[Upload to Backend]
    Q --> R[Clear Queue]
    R --> D
```
